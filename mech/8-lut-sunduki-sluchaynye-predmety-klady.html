8.2. Наполнение сундука [код] PROGRAM/ITEMS/itemLogic.c:808-834

spawnItemsCount = 9 + 9 * Fortune_старая_шкала / 10
   → при Fortune 0: 9 попыток; при Fortune 100 (стар. 10): 9 + 9 = 18 попыток
для каждой попытки вызывается SpawnItem()

SpawnItem [код] itemLogic.c:872-917:

берётся случайный предмет из RandItems (52 записи)
если minLevel предмета > ранг ГГ → отказ
itemProb = атрибут rare предмета (по умолчанию 0.05, т.е. 5%)
для АБОРДАЖНОГО сундука: itemProb *= (1.5 + Fortune_стар/20)
   → при Fortune 100: ×2.0  (при Fortune 0: ×1.5)
itemProb ограничивается 1.0
бросок rand(1000); если > itemProb*1000 → отказ
Предметы с quality >= B_EXCELLENT в сундуках НЕ ГЕНЕРЯТСЯ («отличные клинки в сундуках больше не генерятся»)

[интерпретация] Ожидаемое число предметов в обычном сундуке ≈ 9 * 0.05 = 0.45 при Fortune 0 и 18 * 0.05 = 0.9 при Fortune 100 — то есть навык Удача ровно удваивает лут из сундуков. Для абордажных сундуков ещё ×1.5..×2.0 → до 18*0.05*2 = 1.8 предмета. С учётом того, что редкие предметы имеют собственный rare, реальные значения выше. Также важно: отличного качества (B_EXCELLENT и выше) оружия в сундуках не бывает — только в лавках, у убитых NPC и в кладах.

8.3. Случайные предметы на локации [код] itemLogic.c:504, 524

if (GetCharacterSkillToOld(ГГ, SKILL_FORTUNE) < rand(15)) return;   // предмет НЕ отображается

[интерпретация] Валяющиеся на земле предметы видны с вероятностью Fortune_стар/15: при Fortune 100 (стар. 10) — 10/15 ≈ 67%; при Fortune 45 (стар. 4.5) — 30%; при Fortune < 15 — почти никогда. Это самая недооценённая функция Удачи: без неё вы просто не видите лут в локациях. Проверка выполняется дважды (при спавне и при отрисовке) — фактически шанс (F/15)².

8.4. Ловушки в сундуках [код] itemLogic.c:658

if (GenQuest.God_hit_us == 1 && rand(100) >= (85 + Fortune_старая) && локация не из списка исключений)
   → «Ловушка!» + квест-реакция God_hit_us

[интерпретация] Шанс ловушки = (100 - 85 - Fortune_стар)/100: при Fortune 0 — 15%, при Fortune 100 (стар. 10) — 5%, при Fortune > 150 — 0 (недостижимо). Исключения (сундуки без ловушек): SentJons_HouseF3_Room2, IslaMona_TwoFloorHouse, IslaMona_TwoFloorRoom. Работает только при активном квестовом флаге GenQuest.God_hit_us == 1.

8.5. Респавн сундуков [код] itemLogic.c:740-841

  • Абордажные сундуки (isAbordageBox) наполняются каждый раз заново.
  • Сундуки внутри корабля (isShipInside) и Deck_Near_Ship — не респавнятся.
  • При флаге локации MustSetReloadBack содержимое сундуков обнуляется.
  • После наполнения вызывается FillGenerableItemsForChest — генерируемые предметы (оружие/броня) заменяются на конкретный сгенерированный экземпляр (GetGeneratedItem).

8.6. Карты сокровищ и клады [код] PROGRAM/scripts/Treasure.c

Структура: карта (item) содержит MapIslId (остров), MapLocId (локация), MapBoxId (сундук), MapTypeIdx = rand(2) (0 или 1 — тип отображения карты). [код] Treasure.c:135-138: шанс 1/16 (rand(15)==1), что карта «пустышка» (MapTypeIdx = -1) — если только не активен флаг GenQuest.TreasureBuild (сборная карта), тогда вызывается FillBoxForTreasureSuper. [код] Treasure.c:148: при валидной карте локация клада получает DisableEncounters = true (в ней не будет случайных встреч) и разыгрывается GenQuest.Treasure.Vario = rand(5) — одно из 5 событий у клада.

Содержимое клада — базовое [код] Treasure.c:152+ FillBoxForTreasure(item, rand(3)), тип 0 («good»):

50%: jewelry2  x(2 + rand(30))    ИЛИ  jewelry3 x(10 + rand(3))
50%: gold_dublon x(20 + rand(100))
50%: jewelry3  x(1 + rand(30))
50%: jewelry5  x(5 + rand(60))
50%: jewelry40 x(15 + rand(100))
33%: jewelry41 x(15 + rand(100))
33%: jewelry42 x(5 + rand(100))
33%: jewelry43 x(5 + rand(100))
33%: jewelry44 x(5 + rand(100))

Дополнение [код] Treasure.c:361-465 FillBoxForTreasureAddition:

если 5*Fortune_стар > rand(55)  → кусок сборной карты (map_part1, затем map_part2)
   → при Fortune 100 (стар.10): 50 > rand(55) ≈ 91% шанс;  при Fortune 20 (стар.2): 10/55 ≈ 18%
switch (rand(40)) — один случайный бонус из 28 вариантов (случаи 29-40 = пусто):
   gold_dublon (rand(40)+20) — 3 варианта из 40 (случаи 1, 24, 28)
   jewelry10/11/12/13 — по 1 варианту
   ВСЕ индейские артефакты indian_1..indian_11 — по 1 варианту каждый
   амулеты amulet_1..amulet_8 — по 1 варианту каждый
   Mineral14, Mineral15 — по 1 варианту
+ GenerateMapsTreasure(item, 10, 20) — шанс каждой из 25 карт сокровищ: 1/10 или 1/20

[интерпретация] Шанс получить конкретный артефакт из клада = 1/40 = 2.5%. Шанс получить хотя бы что-то из бонуса = 28/40 = 70%. В каждом кладе также разыгрывается 25 карт сокровищ с шансом 10% (или 5% для map_cayman, map_dominica, map_terks, map_Pearl, map_maine_1, map_maine_2) — то есть клады это основной способ получить новые карты сокровищ. Ожидаемое число новых карт из одного клада ≈ 190.1 + 60.05 = 2.2 (при условии, что карт ещё нет).

[код] Treasure.c:471+ FillBoxForTreasureSuper (только для сборных карт): порог получения куска 3*Fortune_стар > rand(21) → при Fortune 100 (стар. 10): 30 > rand(21) = 100%; при Fortune 23 (стар. 2.3): 33%.

[код] Treasure.c:109-118 Адмиральские карты: только 1 шт., шанс rand(abl) == 1 и только при флаге questTemp.AdmiralMap.

8.7. Воровство/скрытность (по коду)

Отдельной «системы карманных краж» в скриптах нет; Sneak применяется в: - контрабанда (contraband.c:243 — Sneak < rand(120) → провал); - убийства в городе (LAi_fightparams.c:1025 — Sneak < rand(140) → нация становится врагом); - фальшивый флаг (AIShip.c:1913-1916, формула в п. 7.8); - урон при абордажном сцеплении (AIAbordage.c:138-141 — 1.05 - Sneak/100); - одежда меняет Sneak от −100 (водолазный костюм) до +30 (костюм Лампорта), см. п. 1.14; - артефакты: obereg_4 ×1.15, amulet_6 ×0.50, перк HT2 ×1.15. [интерпретация] Sneak — «универсальный навык безнаказанности». Опыт даётся крупными порциями: +100 за контрабандную сделку, +50 за успешный обман флагом (раз в день).
