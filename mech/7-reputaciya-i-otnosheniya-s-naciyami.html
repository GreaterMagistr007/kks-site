Комплексная репутация состоит из трёх независимых атрибутов: - reputation.nobility — «благородство» (главная шкала, бывшая репутация); - reputation.fame — «известность»; - reputation.authority — «авторитет» (изменения НЕ выводятся в лог, characterUtilite.c:3018).

7.3. Дрейф репутации к нейтралу (важно!) [код] characterUtilite.c:3097-3120 UpdateReputation()

если nobility < 40:  nobility += MOD_SKILL_ENEMY_RATE / 50.0   (растёт к нейтралу)
если nobility > 60:  nobility -= MOD_SKILL_ENEMY_RATE / 25.0   (падает к нейтралу, ВДВОЕ быстрее)
то же самое для fame

[интерпретация] Репутация сама сползает к 50 каждый день. При сложности 4: из плохого +0.08/день, из хорошего −0.16/день. Хорошая репутация теряется вдвое быстрее, чем плохая. На сложности 10: +0.2 / −0.4 в день. Диапазон 40-60 — «мёртвая зона», где дрейфа нет. [интерпретация] Следствие: удерживать крайние значения репутации (важные для найма команды, кредитов, сдачи капитанов) нужно постоянными действиями — само оно уйдёт.

7.6. Отношения с нациями: «награда за голову» (hunter score) [код] RPGUtilite.c:2906-2979

Внутренняя шкала reputation.<nat>hunter от −100 до +100 (стартовое значение −5). ChangeCharacterNationReputation — это тот же счётчик с обратным знаком.

Названия (GetNationReputationName, RPGUtilite.c:2969-2979) — по значению i = -hunter:
   i <= -10  → «Награда за голову (-i*1000)» песо      ← т.е. hunter >= 10
   i < 0     → «Враждебная»                            ← hunter от 1 до 9
   i <= 20   → «Нейтральная»                           ← hunter от 0 до -20
   i <= 50   → «Хорошая»                               ← hunter от -21 до -50
   i <= 80   → «Отличная»                              ← hunter от -51 до -80
   i <= 100  → «Восхищение»                            ← hunter от -81 до -100

[интерпретация] Награда за голову = hunter × 1000 песо и начинается ровно при hunter = 10. Максимальная награда — 100 000 песо (hunter = 100). Атрибут GenQuest.HunterScore2Pause полностью блокирует прирост. Спец-случай: pirhunter игнорируется (RPGUtilite.c:2910) — у пиратов нет награды за голову.

Что повышает hunter (портит отношения) [код]: | Действие | Δ hunter | |---|---| | Убийство горожанина ВРАЖЕСКОЙ нации без оружия в руках | +2 (LAi_fightparams.c:1010) | | Убийство горожанина НЕвражеской нации | +3 (LAi_fightparams.c:1018) | | Обстрел корабля нации, дружественной вашему патенту (патент изымается!) | +40 (AIShip.c:271) | | Обстрел корабля нейтральной нации без патента | +1 + rand(2) (AIShip.c:285) | | Атака командира группы нации (не пираты) | +5 (AIShip.c:328) | | Потопление/захват корабля нации | +1 + rand(1) (AIShip.c:2462, 2668, 2724) | | Проваленное задание капитана (150k) | +50 (GenQuests.c:3008,3015) | | Просрочка займа | +25 (characterUtilite.c:3864) | | Возврат двойного долга ростовщику | −30 (улучшение) |

[интерпретация] Обстрел «своих» под патентом (+40) — самое разрушительное для отношений действие, и патент при этом изымается безвозвратно (AIShip.c:270-276, звание в патенте сбрасывается до 1).

7.7. Убийство в городе → мгновенная вражда [код] LAi_fightparams.c:1023-1031

если убит персонаж с атрибутом City:
   если GetSummonSkillFromName(атакующий, Sneak) < rand(140)
   → SetNationRelation2MainCharacter(нация, RELATION_ENEMY)

[интерпретация] При Sneak >= 140 (недостижимо, максимум 100) вражды не будет никогда. Практически: при Sneak 100 шанс избежать вражды 100/140 ≈ 71%; при Sneak 0 — 0%. Максимальный Sneak — это фактически лицензия на убийства в городах.

Дополнительно [код] LAi_fightparams.c:989-1002: - убийство горожанина Голландии при наличии HolTradeLicence → лицензия аннулируется; - убийство пиратского горожанина → счётчик GenQuest.Piratekill (репутация у пиратов); - убийство индейцев: canib → индейская репутация −0.5, miskito → −1.0, squaw → −2.5.

7.8. Распознавание фальшивого флага [код] AIShip.c:1870-1935 Ship_CheckFlagEnemy

1) Если нация корабля враждебна базовой нации ГГ (и нет голландской грамоты) → флаг проверяется.
2) Иначе: если hunter этой нации > (8 + rand((класс_старшего_корабля - 1)*(6 - число_кораблей)))
   → флаг проверяется.
3) Проверка «раскусили ли»:
   rep = |50 - nobility| * 0.75
   fPerkInfl = 2.0 если перк HT2, иначе 1.0
   если (rand(100) + rand(20) + rand(rep)) > fPerkInfl * Sneak/100 * 10 * класс * (6 - кораблей) * indian_11(1.15)
   → ОБМАН РАСКРЫТ, нация становится враждебной
   иначе Sneak +50 опыта (раз в игровой день)

[интерпретация] Правая часть тем больше (лучше для игрока), чем выше класс корабля (класс здесь — номер, т.е. класс 6 «лучше» класса 1!) и чем меньше кораблей в эскадре (6 - кораблей). То есть флаг лучше всего работает на одиночном мелком корабле — что логично. При эскадре из 6 кораблей множитель (6-6) = 0 → обман раскрывается всегда. Перк HT2 удваивает эффективность скрытности; артефакт indian_11 даёт +15%. Крайняя репутация nobility (0 или 100) добавляет до rand(37) к шансу раскрытия — то есть для контрабанды под флагом лучше держать нейтральную репутацию.

7.9. Смена флага и потеря патента [код] AIShip.c:261-287 Ship_NationAgressivePatent

С патентом: выстрел по кораблю нации, НЕ враждебной нации патента (и не пирату) →
   патент изъят, TitulCur = 1 (звание сброшено), hunter этой нации +40
Без патента: выстрел по НЕвражескому кораблю → hunter +1..2 (единожды на корабль, флаг CheckNationBounty)
Атрибуты-исключения: Coastal_Captain, ShipEnemyDisable, AlwaysFriend — не обижаются на выстрелы

Обстрел корабля СВОЕЙ нации [код] AIShip.c:305-313: игрок автоматически становится пиратом (pchar.nation = PIRATE), nobility −10, authority −2, fame +0.5.

7.11. Отношения нация-нация
