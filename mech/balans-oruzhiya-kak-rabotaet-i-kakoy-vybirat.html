Баланс оружия: как работает и какой выбирать

← вся механика

Раздел собран из кода игры 1.7.3 — все формулы и числа взяты из скриптов, внешние источники приведены отдельно для сверки. Уровень достоверности: [код] — высший (значение прочитано в скрипте), [сверка] — то же утверждение независимо подтверждено внешним источником, [расхождение] — внешний источник расходится с кодом, верить коду.

Что такое баланс [код] ITEMS/initItems.c:3670-3671

blade.Balance = fRandSmall(2.0);          // диапазон 0.00 .. 2.00
if(ModelID == "unarmed") blade.Balance = 1.0;   // у кулаков фиксирован
  • Баланс — свойство экземпляра, а не модели клинка: две «Бретты» с одной полки имеют разный баланс, вес и атаку [код] initItems.c:3654-3703 [сверка] форум и corsairslegacy говорят то же.
  • Шаг значения — 1/16 = 0.0625 (проверено выгрузкой всех клинков из реального сохранения: 0.0000, 0.0625, 0.1250 … 2.0000) [код] + [проверка на сейве].
  • Часть квестовых клинков получает баланс жёстко: 1.0 (Norman.c:505), 1.9 (Puancie.c:1474), 2.0 (Vincento.c:435, reaction_functions.c:29215) [код].
  • На цену клинка баланс не влияет: 35*(1/Curve + Lenght)*(Attack*2-30) для лёгких [код] initItems.c:3705-3728. Идеальный экземпляр стоит столько же, сколько мусорный.

Куда именно входит баланс [код] Loc_ai/LAi_fightparams.c:63-256

Баланс работает через два множителя, и это единственное его применение в бою:

Множитель Формула B = 0 B = 1 B = 2 На какие удары
«к острию» 0.85 + B/6.67 0.850 1.000 1.150 быстрый (fast), пробивающий (break)
«к рукояти» 1.22 - B*0.22 1.220 1.000 0.780 обычный (force), финт (feint, feintc)
— множителя нет 1.000 1.000 1.000 круговой (round)

Отсюда весь размах: переход с B = 2 на B = 0 даёт +56 % к обычному удару и финту и −26 % к быстрому и пробивающему. Обратный переход — +35 % к быстрому и пробивающему и −36 % к обычному и финту. Круговой удар балансом не управляется вовсе [код].

Больше баланс нигде в бою не участвует: ни в скорости ударов, ни в расходе энергии (LAi_fightparams.c:447-495), ни в блоке и парировании. Единственное место вне боя — функция автовыбора оружия, см. ниже [код].

Какой клинок под какой удар [код] initItems.c:101-155

Длина и кривизна фиксированы для модели, поэтому «лучший под удар» определяется однозначно, а баланс добирается перебором экземпляров.

Читается так: у лёгкого клинка обычный удар (force, формула L/C) настолько сильнее остальных, что ослабленный балансом обычный удар всё равно бьёт больнее, чем усиленный балансом быстрый. Асоледа при балансе 0 даёт 1.403 против 0.793 у быстрого удара при балансе 2 — разница почти вдвое [код].

Практический вывод по коду:

  1. Берите баланс 0.0–0.3. Именно он усиливает обычный удар и финт — два удара, на которых лёгкий класс и построен [код] [сверка] (форумная рекомендация «рапира с балансом 0.0–0.3» совпадает).
  2. Длина важнее кривизны. Обычный удар считается как L/C: нужен длинный и прямой клинок. Лучшие лёгкие по геометрии — Асоледа (1.15 / 1.00), затем Стокката и Саксенфедер (1.05 / 1.00), Бретта (1.00 / 1.00) [код].
  3. Обычный удар ещё и самый дешёвый по энергии — 7.0 против 10.0 у быстрого и 18.0 у кругового [код] LAi_fightparams.c:447-495. Стиль «баланс 0 + обычные удары» выгоден дважды.
  4. Баланс 2 у рапиры — испорченная рапира. Он усиливает быстрый и пробивающий, но у лёгкого класса быстрый режется коэффициентом 0.6, а пробивающий — делителем 0.7/L: чем длиннее клинок, тем хуже он пробивает [код].
  5. Исключение — противник, который держит блок. Пробивающий удар при блоке даёт фиксированный kAttackDmg = 1.0 мимо всех формул, то есть параметры клинка в этот момент не важны совсем [код] LAi_fightparams.c:155-157. Против «блокеров» переключайтесь на пробивающий, не меняя клинок.

Ловушка автоподбора оружия [код] characters/characterUtilite.c:2207

curBladeValue = (20 + (0.6*Attack + 0.4*Attack*(навык/100)*(1 + (1-B)*(B-1)/5))) / Weight

Множитель 1 + (1-B)(B-1)/5 = 1 - (B-1)²/5: максимум 1.00 при B = 1, минимум 0.80 при B = 0 и B = 2. То есть встроенная оценка «лучшего клинка» считает лучшим ровно тот баланс, который в бою хуже всего, и вдобавок делит на вес. Отсюда известная жалоба, что офицер сам берёт палаш вместо выданной рапиры [код] [сверка] (форум: «функция определения лучшего клинка» — офицер перебирает инвентарь сам). Вывод: клинок офицеру выдавать вручную и проверять после боёв.

«Рапира с балансом 0.0–0.3 для одиночных боёв» форум совпадает с расчётом [сверка]
«При балансе около 2 финт почти бесполезен, 4–5 HP за удар» форум объясняется кодом: 0.9/L/C * 0.78, для длинного клинка это худший удар в наборе [сверка]
«Пробивающий удар часто слабее обычного даже при балансе 1.7» форум [спорно] подтверждается для лёгких клинков: 0.7/L против L/C — пробивающий проигрывает обычному в разы; для тяжёлых наоборот [сверка]
«Вес и баланс каждого экземпляра случайны» форум, corsairslegacy совпадает: fRandSmall в initItems.c:3654-3670 [сверка]

Ни один внешний источник не описывает поведение кругового удара верно и ни один не упоминает ловушку автоподбора — эти два факта есть только в коде.

Как искать нужный экземпляр

  1. Баланс виден в описании предмета, длина и кривизна — скрытые параметры, они постоянны для модели: таблица в разделе 12.3 [код].
  2. Клинки лучшего качества (EXCELLENT) дают атаку 85–100 % от потолка класса (60 / 80 / 100), квестовые отличные — ровно потолок [код] initItems.c:3670-3703.
  3. Перебирать экземпляры проще всего у лавочника и в кладах: цена от баланса не зависит, поэтому «идеальный» клинок не дороже обычного [код].
  4. Проверить параметры конкретного экземпляра в своём сохранении можно редактором сейвов: sdedit.py читает массив Items (attack, balance, weight, lenght, curve).
