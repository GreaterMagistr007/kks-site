9.1. Морские энкаунтеры: полная таблица [код] PROGRAM/Encounters/encounters.h, Encounters_init.c

MAX_ENCOUNTER_TYPES = 27. По умолчанию у каждого типа Chance = 100, MinRank = 1, MaxRank = 1000. Выбор типа: iChance = rand(250) (в некоторых местах rand(200)), тип проходит, если iChance <= Chance (Encounters.c:34,42,67,75,100,108,133,141). [интерпретация] Значит фактическая вероятность типа = Chance/250 (или /200), т.е. Chance = 100 → 40%, Chance = 25 → 10%, Chance = 45 → 18%.

9.2. Сухопутные энкаунтеры [код] PROGRAM/Loc_ai/LAi_monsters.c:271-1103 LAi_CreateEncounters

Условия генерации (все должны быть выполнены):

bLandEncountersGen == true  (_LSC_on_off.h:54, по умолчанию true)
!bDisableLandEncounters     (_LSC_on_off.h:28, по умолчанию false — «запрет всех случаек на суше,
                             офицеры и клады тоже»)
локация имеет locators.encdetector
CheckNPCQuestDate(location, "Enc_date") — не чаще одного раза в игровой день на локацию
нет атрибута DisableEncounters, fastreload, ItzaLand, onUninhabitedIsland-исключений
нет флага GenQuest.Enc2Pause (одноразовая пауза)
нация ближайшего города не PIRATE и не -1
в бухте (seashore) с контрабандистами (модель "smg") энкаунтеры НЕ ставятся

Ранг противников [код] LAi_monsters.c:359-365, 896-902:

если ранг ГГ <= 6:  iRank = ранг ГГ
если ранг ГГ > 20:  iRank = ранг ГГ + MOD_SKILL_ENEMY_RATE * 2.5 / число_врагов
иначе (7..20):      iRank = ранг ГГ + MOD_SKILL_ENEMY_RATE * 1.6 / число_врагов
Число врагов = число локаторов в группе − rand(2), минимум 1

[интерпретация] Противники всегда подстроены под ваш ранг — прокачка не облегчает наземные встречи. На сложности 10 и ранге > 20 бонус к рангу врагов: 25/num (при 4 врагах +6 к рангу каждому).

9.3. Пещерные энкаунтеры [код] LAi_monsters.c:1105-1343 LAi_CreateCaveEncounters

только для локаций с type == "cave"
не чаще 1 раза в игровой день (атрибут enc)
исключены: Ksochitam_*, mine_*, Bermudes_Cavern, FortFrance_Dungeon
шанс: drand(12) > 5 → отказ, т.е. вероятность события ~50%
ранг противников: iRank = 8 + ранг_ГГ + MOD_SKILL_ENEMY_RATE/2
вариант: rand(4) → 0..4 (фактически 0..3, случай 4 достигается редко)

1 Карибы (индейцы)

4 Заполнение сундука в пещере (см. ниже)

Содержимое пещерного сундука [код] LAi_monsters.c:1315-1338:

sJew = jewelry(12..22);  sGem = jewelry(1..5);  sMin = mineral(13..25)
sItm = один из indian_1..11 / amulet_1..11 / obereg_1..11 (drand(2) выбирает группу)
10%: gold_dublon x drand(100)
10%: chest x drand(1)
10%: jewelry7 x drand(3)
10%: jewelry5 x drand(100)
10%+10%: jewelry6 x drand(200)  (два независимых броска)
40% (drand(10) > 5): случайный минерал x1
14% (drand(7)==0): АРТЕФАКТ (indian/amulet/obereg) x1
14% (drand(7)==1): sJew x drand(20)
14% (drand(7)==2): sGem x drand(30)

[интерпретация] Пещеры — лучший источник артефактов после кладов: 14% шанс артефакта на каждый сгенерированный пещерный сундук, при том что событие происходит примерно раз в день с вероятностью 50% в каждой пещере (и вариант «сундук» — 1 из 5). Ранг скелетов 8 + ранг_ГГ + MOD/2 — они всегда сильнее ГГ.

9.4. Прочие генераторы на локациях [код] LAi_monsters.c

  • LAi_CreateFlowers (строка 122) — генерация травы/растений.
  • LAi_CreateQuestFlowers (149) — рассада квестовой травки (Мангароса).
  • LAi_CreateShoreChest (166): выброшенные на берег сундуки — шанс drand(100) < 5 = 5% на локациях type == "seashore". Модель chest_1 или chest_2, содержимое через FillShorechestBox(loc, num, drand(5)). Сундук исчезает через 2 игровых дня (GetNpcQuestPastDayParam(location, "chest_date") > 2).
  • LAi_CreateDolly (225) — телепортационные статуи (предметы dolly0..dolly5).
  • LAi_CreateParticles (1345) — партиклы окружения.
  • [код] _LSC_on_off.h:52 bMonstersGen = false — генерация монстров по умолчанию ВЫКЛЮЧЕНА.
  • [код] locations/init/Ksochitam.c:74,195,317,476 число скелетов в локациях Ксочитама: 10 + MOD/2, 9 + MOD/2, 4 + MOD/2, 10 + MOD → на сложности 10: 15, 14, 9, 20 монстров.

9.5. Животные и окружение [код] PROGRAM/animals.c

Чисто декоративные объекты, боевого значения нет: - чайки (MSG_ANIMALS_SEAGULLS_SHOW) — только днём, не в дождь, не в шторм, при environment.weather == true; - бабочки — только в локациях type == "jungle", днём, не в дождь/шторм; - косяки рыб (MSG_ANIMALS_FISHSCHOOLS_SHOW) — только в море. [интерпретация] Наличие/отсутствие чаек и бабочек — визуальный индикатор погоды и времени суток.

9.6. Погонная логика фантомов [код] AIShip.c:4266-4272

если GetNpcQuestPastTimeParam(rCharacter, "Add2SeaTime") > 55 (≈2 дня для фантома)
   → Ship_SetTaskRunaway(...) — корабль начинает убегать от ГГ

[интерпретация] Любой сгенерированный корабль через ~2 суток погони начинает убегать, а не атаковать. Пересчёт временных навыков (TmpSkillRecall) — раз в 25 + rand(49) кадров/вызовов.
