5.2. Формула цены товара [код] PROGRAM/store/storeutilite.c:114-239

итоговая цена = priceModify * basePrice * tradeModify * skillModify * qty * costCoeff * cModify
tradeModify по ТИПУ ТОРГОВЛИ в этом городе (TradeType):
   NORMAL      1.00 + RndPriceModify
   EXPORT      0.80 + RndPriceModify     ← дешевле всего (город производит)
   IMPORT      1.20 + RndPriceModify
   AGGRESSIVE  1.40 + RndPriceModify     ← дороже всего (город остро нуждается)
   CONTRABAND / AMMUNITION / CANNONS  1.00 + RndPriceModify
tradeModify *= AddPriceModify           // = 1.05 - (запас/норма)/20   (storeutilite.c:476-480)
priceModify по ТИПУ ТОВАРА (Type): NORMAL/AMMUNITION/CANNONS 1.0, EXPORT 2.0, CROWN 5.0, IMPORT 3.0, UNIQUE 10.0
ПОКУПКА игроком:  skillModify = 1.325 - Commerce_старая*0.005    (при Commerce 100 → 1.275)
                  − 0.15 ProfessionalCommerce / − 0.10 BasicCommerce
                  с перком HT2: − 0.20 / − 0.15 / − 0.05
                  для пушек: cModify = 3.0 + MOD_SKILL_ENEMY_RATE/5.0  ← пушки в лавке в 3.8-5 раз дороже!
ПРОДАЖА игроком:  skillModify = 0.675 + Commerce_старая*0.005    (при Commerce 100 → 0.725)
                  + 0.15 ProfessionalCommerce / + 0.10 AdvancedCommerce
                  с HT2: + 0.20 / + 0.15 / + 0.05
                  * costCoeff (Goods.<товар>.costCoeff у ГГ)

[интерпретация] - Навык Commerce влияет очень слабо: от 1.325 до 1.275 при покупке (−3.8%) и от 0.675 до 0.725 при продаже (+7.4%). Перки казначея (10-15%) сильнее навыка Commerce в 2-4 раза. - Спред «купил-продал» без перков: 0.675/1.325 = 51% — т.е. мгновенная перепродажа теряет ~49%. С ProfessionalCommerce+HT2: 0.875/1.125 = 78% (потери 22%). - Максимальная разница цен между городами: EXPORT (0.80) vs AGGRESSIVE (1.40) = 1.75× плюс RndPriceModify до ±0.15 и AddPriceModify ±5% → до ~2.2× на маршруте. - Самые «дорогие» товары по priceModify: UNIQUE (×10) — тросы, масло, шёлк, сандал; но в лавках их нет. - Пушки покупать в лавке крайне невыгодно (cModify 3.8-5.0), а вот у контрабандистов [код] smuggling.c:484,508 cModify = 2.0 - MOD_SKILL_ENEMY_RATE/20.0 = 1.8-1.9 → вдвое дешевле.

5.3. Как формируется запас в лавке [код] PROGRAM/store/initStore.c:95-160

Начальное количество (= Norm магазина, фиксируется на всю игру): | TradeType в городе | Начальный запас | |---|---| | NORMAL / AMMUNITION | Norm*0.75 + rand(Norm*0.1) | | EXPORT | Norm*0.9 + rand(Norm*0.2) ← максимум | | IMPORT | Norm*0.4 + rand(Norm*0.05) | | AGGRESSIVE | Norm*0.1 + rand(Norm*0.05) ← минимум | | CONTRABAND | Norm*0.1 + rand(Norm*0.05) | | CANNONS | Norm*0.4 + rand(Norm*0.4), либо 0 если NotSale | Затем ×MediumNorm (средняя лавка) или ×SmallNorm (малая).

RndPriceModify [код] initStore.c:50-60: разыгрывается один раз на ОСТРОВ: frnd()*0.15; знак RndPriceModifySign = -1.0 по умолчанию, но +1.0 если город главный в нации (ismaincolony) или пиратский. [интерпретация] Значит: в главных колониях и у пиратов цены систематически выше (до +15%), в остальных — ниже (до −15%). Пушки: RndPriceModify = (frnd()*0.03 + RndPriceModify + 0.10) * знак.

Ежедневный оборот [код] storeutilite.c:361-418 UpdateStore():

Aim = frnd(); если < 0.25 → +1 (товар привезли); если > 0.70 → -1 (увезли); иначе 0
Aim = Aim * Norm * (frnd()*0.2 + frnd()*0.2 + 0.1)     // т.е. ±10..50% нормы
Manufacture = 0.2 (если товар не вывозили); Consumption = 0.1 (если запас > 0.25*Norm)
oldQty += Aim
если oldQty < 1.75*Norm:  Quantity = oldQty + (Manufacture - Consumption)*Norm
иначе (перезатарено):     15% шанс «ревизор» → Quantity = Norm*frnd();
                          иначе Quantity = Norm*(1.75 + frnd()*0.25)

[интерпретация] Магазин пополняется сам на +20%−10% = +10% нормы в день, максимум затаривания 2.0×Norm. Опустошив лавку, полное восстановление занимает ~10 игровых дней. Раз в 6-7 дней есть шанс «привоза» до +50%. Магазины обновляются по одному раз в день (storeutilite.c:498-511, интервал 200 мс на магазин).

5.9. Раздел добычи (bPartitionSet) [код] Crew.c:100-105, 383-520

Веса долей:

Part_HeroPart = 200;  Part_CompanionShipPerClass = 20;  Part_Gower = 10;
Part_Crew = 1;  Part_Companion = 30;  Part_Officer = 10
доля ГГ:  part = 200 + (10 - MOD_SKILL_ENEMY_RATE)*200
          → сложн.2: 1800;  4: 1400;  6: 1000;  8: 600;  10: 400
          + 20*(6 - класс_каждого_корабля_эскадры)
доля губернатора (если есть патент): HowGower = 10 + MOD_SKILL_ENEMY_RATE процентов от дохода
доля команды:   HowCrew = число_матросов * 1
доля офицеров:  HowOff = число_офицеров*10 + число_компаньонов*30
fCrewPart = HowCrew/(HowCrew+HowOff+HeroPart);  fOffPart = HowOff/(...)

[интерпретация] На «лёгком» доля ГГ (1800) при 300 матросах = 1800/(300+HowOff+1800) ≈ 83%. На «сложном» (400) при тех же 300 → 400/2100+ ≈ 55%. Уровень сложности напрямую режет вашу долю добычи с ~83% до ~55%. Патент отнимает ещё 12-20% сверху. Мелкие корабли в эскадре увеличивают долю ГГ (20*(6-класс): тартана даёт +0, а линкор класса 1 даёт +100 — то есть чем крупнее корабли эскадры, тем больше доля ГГ; читать формулу: класс 1 → 205 = 100). Флаг bPartitionSet (_LSC_on_off.h:99, по умолчанию true*) включает раздел; на сложности 10 он принудительно включён и не отключается (selectCharacter.c:302-330). Долг перед командой копится в Partition.MonthPart и, как и невыплаченное жалованье, снижает мораль на −1 в день. Атрибут GenQuest.DontPartition отменяет раздел за конкретный рейд.
