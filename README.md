# Справочник «Корсары: Каждому Своё» 1.7.3

Оффлайн-справочник по игре *Корсары: Каждому Своё* (Sea Dogs: To Each His Own), версия 1.7.3 x64, все пять DLC.

**Сайт: https://greatermagistr007.github.io/kks-site/**

## Как пользоваться без интернета

Сайт устанавливается на телефон как приложение и после первой загрузки работает полностью автономно.

1. Откройте ссылку выше в Chrome на Android.
2. Меню браузера → «Установить приложение» (или «Добавить на главный экран»).
3. Дождитесь, пока строка на главной странице скажет «Оффлайн-копия готова».
4. Дальше интернет не нужен: страницы, карты и поиск работают из локального кэша.

На главном экране появится иконка, приложение открывается в своём окне без адресной строки.

## Что внутри

- 126 квестов: где начинается, требования, таймеры, шаги, награды
- 30 городов с ценами покупки и продажи по 47 позициям
- 138 карт: архипелаг, острова, города, гроты, подземелья
- механика из скриптов игры: перки, формулы прокачки, корабли, пушки, экономика, репутация
- таймеры и точки невозврата, достижения Steam, поиск по всему справочнику

## Источники

Скрипты установленной игры версии 1.7.3 x64 (основной источник), Steam-руководства, форум Корсарской Гавани, pirates-life.ru, вики «Корсары», corsairslegacy.com.

## Сборка

Репозиторий содержит готовую статику. Она собирается из исходников справочника скриптами `webp_convert.sh` (сжатие карт в WebP) и `make_dist.py` (сборка страниц и service worker), которые в этот репозиторий не входят.
